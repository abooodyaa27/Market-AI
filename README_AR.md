# Market AI V2

تطبيق Android محلي لعرض وتحليل Gold (XAUUSD) وBitcoin (BTCUSD)، كل أصل ببيانات وحالة مستقلتين. لا يرسل أوامر تداول، ولا يتضمن مفتاحاً أو اتصالاً بـOpenAI.

## التسلسل التحليلي

1. **H4 Bias**: EMA20/50 وميل EMA20 على ثلاث شموع، مع فحص السوينغات المؤكدة (شمعتان يمين ويسار). سماحية مقارنة السوينغات 0.12 ATR لتجنب تفسير فرق صغير كعكس اتجاه. البنية المعاكسة أو كسرها المعاكس يمنع الإشارة.
2. **H1 Structure**: تأكيد اتجاه متوافق مع سوينغات متوافقة أو كسر بنية مؤكد؛ الاتجاه المحايد أو المعاكس ينتج WAIT.
3. **M15 POI**: أحدث سوينغ صالح من آخر 30 شمعة، منطقة من الذيل إلى الجسم مع هامش 0.1 ATR وعرض أقصى 1 ATR. يجب ظهور ابتعاد مغلق عنها بمقدار 0.2 ATR؛ الإغلاق خلفها بأكثر من 0.1 ATR يبطلها. القرب المسموح 0.2 ATR من الجانب الخارجي و0.35 ATR من جهة الارتداد.
4. **M5 Setup**: ملامسة المنطقة خلال آخر خمس شموع وبعد نشأتها، وإغلاق اتجاهي فوق/تحت EMA20 ومتقدم عن الإغلاق السابق. الجسم لا يقل عن 0.1 ATR والمدى لا يتجاوز 2 ATR.
5. **M1 Trigger**: إغلاق يكسر قمة/قاع الشموع الخمس السابقة بأكثر من 0.05 ATR، جسم اتجاهي لا يقل عن 0.15 ATR ومدى لا يتجاوز 1.8 ATR. يبقى السعر في جهة الكسر وعلى مسافة لا تتجاوز 0.5 ATR من إغلاق التفعيل.

التحليل يستخدم الشموع المغلقة المؤكدة من المصدر فقط. ATR هو متوسط True Range لآخر 14 شمعة. يلزم 55 شمعة مغلقة لكل فريم واتصال نافذة التفعيل: آخر 6 شموع M1 وآخر 5 شموع M5؛ تقادم/فجوات البيانات ينتج WAIT. لا تمنع فجوات الجلسات التاريخية على الفريمات العليا التحليل، وATR يحتسب فرق الافتتاح. بعد فتح السوق يُنتظر إغلاق شمعة حديثة لكل فريم.

وقف إرشادي خلف أقصى آخر خمس شموع M1 بهامش 0.2 ATR؛ المخاطرة المقبولة من 0.5 إلى 3 ATR. الأهداف 1R/1.75R/2.5R. المستويات يعاد حسابها مع السعر وليست صفقات محفوظة أو منفذة. عندما لا تتحقق جميع المراحل، المستويات null وتعرض **—** مع **لا توجد صفقة حالياً**.

## البيانات والعرض

المصدر https://biquote.io. تحديث السعر والشمعة الجارية كل ثانية أثناء فتح التطبيق، دون تعديل الشموع المغلقة. جلب الشموع كل 30 ثانية، وبوتيرة خمس ثوانٍ عند انتظار تأكيد إغلاق الدقيقة. الطلبات لها مهلة ثماني ثوانٍ ولا تتداخل طلبات السعر للأصل نفسه. فشل أصل لا يمنع الآخر.

التحليل يتوقف بعد خمس ثوانٍ دون استلام سعر، أو عشر ثوانٍ من وقت المصدر إذا وفره، أو 90 ثانية دون تحديث فريم. إن لم يوفر المصدر توقيتاً، يعرض التطبيق ذلك صراحة، ويقيس حداثة الاستلام فقط؛ لا يضمن حداثة السعر الأصلي. حالة سوق غير مفتوحة ومعلنة تمنع الإشارة.

H4 يعرض حتى 24 شمعة وH1 حتى 30 بحسب عرض الهاتف. التاريخ والوقت في سطرين، والتفاصيل تظهر بلمس الشارت. قياسات نسبية إلى ATR مستخدمة للأصلين، مع فصل كامل للبيانات والحالة.

## الاختبار والبناء

- `npm test`: حالات BUY/SELL لكل أصل، WAIT بلا مستويات، بيانات ناقصة/قديمة/غير صالحة، انعكاس H1، فشل M5/M1، عدم استخدام الشموع المفتوحة، إبطال POI، وتحديث الشمعة دون تغيير التاريخ.
- `npm install && npx playwright install chromium && npm run test:ui`: تشغيل الواجهة الفعلية ببيانات سوق اختبارية، وفشل شبكة لأصل واحد، وفحص أحجام جوال متعددة.
- GitHub Actions يشغّل الاختبارات، ثم Android assembleDebug وlintDebug وفحص توقيع APK. الناتج Artifact باسم `Market_AI_V2.apk`.

هذه اختبارات صحة برمجية على سيناريوهات مصطنعة، وليست Backtest أو دليلاً على ربحية الإشارات. لا توجد ادعاءات بدقة/عائد مثبتين. لم يُضف أي فلتر ساعات تداول.

النسخة موقعة بمفتاح تجريبي؛ قد يلزم حذف V1 قبل تثبيت V2 لأن مفتاح بناء V1 لم يُحفظ. يُحفظ مفتاح V2 في cache للبناءات التالية؛ حذف cache قد يغيره. قبل توزيع إصدار إنتاجي يلزم مفتاح إصدار دائم محفوظ خارج المستودع.
